# Secondary Higher Education & High School Datta Khel - School Website

Streamlit app with online admission, login/registration, teacher & student attendance,
admin management and a Groq-powered AI assistant.

## Files
- `app.py` - the complete application
- `requirements.txt` - Python packages
- `secrets.example.toml` - example of the secrets you must set
- `.gitignore` - keeps database and secrets out of GitHub

## Run locally
```bash
pip install -r requirements.txt
mkdir .streamlit
# create .streamlit/secrets.toml using secrets.example.toml
streamlit run app.py
```

## Deploy (GitHub + Streamlit Community Cloud)
1. Create a GitHub repository and upload `app.py`, `requirements.txt`, `.gitignore`, `README.md`.
   Do NOT upload your real API key or `secrets.toml`.
2. Go to https://share.streamlit.io, sign in with GitHub, click **New app**, choose your repo, branch `main`, main file `app.py`.
3. Open **Advanced settings -> Secrets** and paste the content of `secrets.example.toml` with your real values
   (Groq key from https://console.groq.com/keys, and a strong admin password).
4. Deploy.

## First use
- Login with the admin username/password you set in secrets.
- **Add Teacher** and **Add Student** create the records and their login accounts.
- Public visitors can **Apply Online** and **Track Application** with the tracking ID + phone.
- Admin reviews applications: set Approved, then press **Admit as student** to create the student account.
- Admin and teachers mark attendance daily; students/teachers see their own attendance after login.

## Roles
| Role | Can do |
|------|--------|
| admin | everything: applications, add/delete students and teachers, attendance, reports, backup |
| teacher | mark student attendance, view students, view own attendance |
| student | view own attendance |
| applicant | register, apply online, see own applications |

## IMPORTANT: data storage
This app uses SQLite (`school.db`). On free Streamlit Community Cloud, local files can be
erased when the app restarts or is redeployed. Use **Dashboard -> Download database backup**
regularly. For permanent production use, move to a hosted database (Supabase / Neon PostgreSQL / Turso).
